# Meesho fixtures

The authorized local fixtures cover XpressBees, Valmo, and Delhivery carrier
variants of the same Meesho Sub Order layout. The complete package content,
including its recipient invoice section, is retained while bottom/outer
whitespace is trimmed. Raw PDFs are Git-ignored because they contain shipping
PII; `manifest.json` stores non-PII hashes and expected outcomes.
